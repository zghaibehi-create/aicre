# Reporting a security issue

Please do not report exploitable vulnerabilities in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the repository maintainers through a private channel listed in the GitHub profile or repository settings and request a private security-reporting route. Do not attach inventories, filenames from private directories, credentials, or personal data.

Include the affected AICRE version, operating system and filesystem where known, a concise impact description, and safe reproduction steps that use disposable test data only.

AICRE is an experimental metadata-inventory prototype. Do not use it as a security boundary or with elevated privileges.
